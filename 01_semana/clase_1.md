# Unidad 1 - Principios Básicos de JavaScript y Backend

# 1. Introducción al Desarrollo Web

## ¿Qué es el desarrollo web?

El desarrollo web consiste en la construcción y mantenimiento de sitios y aplicaciones dentro de la World Wide Web (WWW).

### Evolución
- Páginas estáticas.
- Sitios dinámicos.
- Aplicaciones web completas.

---

# 2. Frontend y Backend

## Frontend

Es la parte visual e interactiva de una aplicación.

### Características
- Interfaz gráfica.
- Botones.
- Colores.
- Formularios.
- Experiencia de usuario.

## Backend

Es la parte lógica y de procesamiento interno.

### Características
- Lógica de negocio.
- Manejo de datos.
- Servidores.
- Bases de datos.
- Procesamiento de información.

## Relación entre ambos

Frontend y Backend son complementarios y trabajan juntos para construir aplicaciones completas.

---

# 3. Stack MERN

## ¿Qué es un stack?

Conjunto de tecnologías compatibles que permiten desarrollar aplicaciones completas.

## Componentes

### MongoDB
- Base de datos NoSQL.

### ExpressJS
- Framework para servidores en Node.js.

### ReactJS
- Librería para interfaces de usuario.

### NodeJS
- Entorno de ejecución de JavaScript.

---

# 4. JavaScript en Navegador y Node.js

## Cliente Web

JavaScript puede ejecutarse desde el navegador.

### Características
- No requiere instalación.
- Se usa desde la consola web.

## Node.js

Permite ejecutar JavaScript fuera del navegador.

### Características
- Requiere instalación.
- Se ejecuta desde terminal (CLI).
- Muy utilizado en Backend.

## Idea principal

Navegador y Node.js son herramientas complementarias.

# 7. ECMAScript y ES6

## ECMAScript

Es el estándar que define cómo funciona JavaScript.

### Versiones
- ES6
- ES7
- ES8
- etc.

## Cambios importantes de ES6

### let
- Scope de bloque.
- Permite reasignar.

### const
- Scope de bloque.
- No permite reasignación.

## Concepto importante

```text
NO REASIGNABLE ≠ INMUTABLE
````

Un objeto o array declarado con `const` puede modificar sus valores internos.

---

# 8. Scope

## Scope Global

La variable puede utilizarse en todo el archivo.

## Scope Local

La variable solo existe dentro de una función o bloque.

## Beneficio

Permite reutilizar nombres de variables sin conflictos.

# 9. Funciones

## Definición

Bloques de instrucciones reutilizables.

## Tipos

### Función tradicional

* Sintaxis clásica.

### Arrow Function

* Sintaxis reducida.
* Return implícito.
* Muy utilizada en desarrollo moderno.

# 10. Template Strings

## Características

* Permiten insertar variables.
* Evitan concatenaciones.
* Soportan saltos de línea.
* Usan backticks (` `).

---

# 11. Closures

## Definición

Funciones que conservan acceso a variables de su función padre.

## Uso principal

* Encapsulamiento.
* Variables privadas.

## Observación

Actualmente las clases reemplazan muchos casos donde antes se usaban closures.

---

# 12. Clases en JavaScript

## ¿Qué es una clase?

Molde para crear objetos.

## Conceptos

### Instancia

Objeto creado desde una clase.

### Métodos

Funciones internas de la clase.

### Variables estáticas

Variables compartidas por todas las instancias.
