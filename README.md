# Backend con JavaScript - Recursos de Estudio y Práctica

Repositorio de apoyo para el curso de Backend con JavaScript orientado a Node.js y MERN Stack.

Este proyecto acompaña los contenidos introductorios vistos en clase:

- Diferencias entre Frontend y Backend
- Node.js
- Variables y tipos de datos
- ES6
- Scope
- Funciones
- Template Strings
- Closures
- Clases en JavaScript
- Consola y debugging
- Introducción al stack MERN

---

# Objetivos

- Aprender fundamentos sólidos de JavaScript moderno
- Entender cómo funciona el backend
- Practicar lógica y estructuras básicas
- Familiarizarse con Node.js y el entorno CLI
- Prepararse para Express, APIs y bases de datos

---

# Recomendaciones para aprender mejor

* Practicar todos los días aunque sea 30 minutos
* Subir ejercicios a GitHub
* Leer errores de consola cuidadosamente
* Intentar resolver problemas antes de buscar la solución
* Construir proyectos pequeños constantemente


# Buenas prácticas

* Usar nombres claros para variables
* Modularizar el código
* Comentar sólo cuando sea necesario
* Mantener funciones pequeñas
* Usar `const` por defecto
